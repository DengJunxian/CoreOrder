# 成员 A 论文记录

## P01 平台与复现

Methods 记录 PAMS 固定提交和 EPL-1.0 来源，金融平台归属上游。Taskflow 和 pybind11 的固定版本与许可列在复现清单，编译配置以实际 Release 命令为准。

P01 结果支持本机基础工具链可重建。金融轨迹、堆恢复、原生 FCN、布局与性能结论等待对应阶段的实际验证和测量。

## P02 串行参考和语义继承

Methods 可引用固定 PAMS 的 `SequentialRunner` 及官方 CI2002 配置作为串行基准。CoreOrder 的 P02 贡献是可追溯运行入口、原配置和独立调用 reference，业务公式、激活与下单规则、订单簿、撮合、账户和事件继续由 PAMS 驱动。

诊断核验中，官方 600 步的价格记录与直接 reference 相同。24 代理的同 seed smoke 在 `py-seq` 两次运行及 reference 中给出一致的有序交易和终态。时长包含观察器开销，正式实验需另用冻结的对照与计时边界。

## P03 接口与样本的证据范围

复现资产包括 112/16 字节的公共 ABI、基于原版 PAMS 的固定 seed 市场/FCN/事件状态 fixture、schema 和同机可执行的构建检查。A 的快照捕获和原版 reference 可显示实际数据及接口边界。独立等价结论须由 E1 和 G0 审核支持。

## P04 复现证据口径

可记录的环境证据为干净 macOS ARM64 候选重建、三组串行诊断运行、真实 fixture 再生和公共 ABI 实测。原版与项目路径共用全量观察器，官方 CI2002 打印链提供市场观察交叉核对。独立等价结论和生产原生路径的验证等待各自的验收证据。 [验收报告](../../gates/G0.md)

## P05 订单簿恢复

测试中的增量恢复从固定 PAMS 的剩余合法堆出发，将撮合扫描暂取的原对象逐项压回。同侧严格顺序来自 PAMS 的市价优先、限价、挂单时间与唯一订单 ID。同一集合在两种合法堆上有相同的后续出堆顺序，PAMS 继续按原配对与统一价格结算。

在 P04.5 集成基线上，A 侧 18 对仿真验证有序事件、逐步状态、市场历史和最终完整 RNG。以 E 的采集器和固定原版 PAMS 复验 C01a、C01b、C01g，各五种子，15 对一致。CI2002 smoke 的 12 次恢复中，买卖侧比较次数分别从 433、377 降至 97、93。这些计数描述恢复阶段的算法工作量。端到端时长、硬件 cache 计数及收益边界需要正式性能数据。 [方法、边界与复现](HEAP_METHOD.md)

## P06 独立复验记录

固定原版 PAMS 对照 P05 的增量路径，组长采集的 23 对完整仿真与 8 个定向场景在事件、逻辑簿、历史、账户和 RNG 上一致。E 的固定验证器另检查 38 对完整仿真，与既有复验结果一致。独立记录确认恢复段的比较数量减少，建簿、非堆顶移除和到期清理调用点保留。数据支持受测范围的语义等价和恢复工作量分析。正式端到端时间与硬件计数等待对应实验。 [G1-heap 记录](../../gates/G1-heap.md)

## P07 确定性原生串行批次

普通 FCN 决策按原 PAMS 抽样顺序分批。将宽度限制在剩余非空代理名额内，可以在批量求值时保持原串行会调用的代理集合。D 从实时状态打包，B 的原生串行核执行数值计算，A 依原调用和市场顺序回建订单。两套完整市场在有序事件、逐步状态、终态和全量 RNG 上与固定 PAMS 一致。normal 双市场用例覆盖无单补批、稀疏访问、基本面冲击及原版 HFT。正式性能仍需独立计时。 [方法、范围与证据](INTEGRATION.md)

## P09 生产系统组合

保留 PAMS 对订单决策与市场更新的因果边界。A 只将安全批次中的原始随机样本和市场字段交给 B 的唯一核。C 的 Taskflow 分块不改变每行写入位置，D 的内存布局可以独立切换。PAMS thread/process 作为上游对照，spawn 的实际序列化分发字节只用于说明复制开销。27 次代表运行相对固定 PAMS 的轨迹等价，端到端性能需要后续实验。 [集成证据](INTEGRATION.md)

## P11 堆机制和残余成本

W2-H seed 11 在相同事件和 2,423 次双方恢复下，专门统计到的恢复比较从 8,245,535 次降至 92,206 次。两侧深度中位数为 925/812，暂取中位数为 2/2。W1-H 的增量路径保留了全普通代理排列与撮合开销，W2-H 的原生串行 pilot 也保留了较慢样本。硬件频率和 PMU 缺测，当前解释基于操作与阶段诊断。 [结果与限制](RESULTS.md)
