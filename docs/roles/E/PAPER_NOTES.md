# E 的论文方法素材

我们以固定 PAMS 的未修改金融实现为独立参考，不用被测原生公式计算期望值。验证分为写入顺序事件、每个完成步骤的结构状态以及最终完整随机状态；价格和现金等浮点逐值保留 hex 表示，逻辑订单簿按上游比较器编码，内部堆布局不视为金融语义。SHA256用于快速索引和证据关联，首分歧仍展开结构。观察器只增加读取，不更改撮合、策略、账户与随机消费。

可信实验要求先验证后测量：全量 trace 与低开销计时分开，系统时间包含随机准备、packing、原生计算、订单重建与撮合。五个 seed 是市场样本层级，每 seed 三次计时为技术重复；应按同一区组内 log ratio，再按 seed 聚合，避免伪重复。超时保留右删失，缺测值 null 加原因，后备模式按 effective backend 过滤。该设计依据公共09协议与 Kalibera–Jones，不是新的统计方法。

当前仅模块开发证据，不含正式性能结论、系统加速比或硬件 cache 论断。G0/G1/G2/G3 由对应真实依赖和验收记录决定。局限：有限 fixture 不证明全部扩展模型；跨 ISA/libm 不预设位级等价；5 seed 对总体外推有限。各金融/运行时/布局方法由原作者和模块所有者署名，E仅承担独立证据工具。
