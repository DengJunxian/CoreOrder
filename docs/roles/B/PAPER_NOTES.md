# B 模块论文方法与答辩素材

FCN 策略从现价、历史价、基本面和高斯随机输入计算预期价格。模块实验中，未改动的 PAMS 负责参考订单和随机流，C++ 接收同样的抽样值并按上游表达式计算。两种布局共用同一标量函数，并在直接串行路径绕开运行时调度。验证比较限价订单的身份、方向、原始价格的十六进制表示、数量、TTL，以及每次调用后的完整 Python 随机状态。Normal margin 的第二次高斯调用在无订单时仍然发生，可以用空单验证随机状态严格一致。

| 答辩素材 | 屏幕上展示的证据 |
| --- | --- |
| 从原版 FCN 到纯数值计算 | 用示意图标出 Python 取行情与随机数、C++ 计算和 Python 回填三个边界。用 normal 空单说明为何必须保留 `gauss` 的调用次数与缓存。 |
| 正确性与适用边界 | 展示生产 ABI 下的两布局差分、24 条公共数值样本与错误路径。用跨主机高斯末位差作为预期边界。微基准的时间范围限于串行模块接口，可展示小批量时固定验证的相对成本。 |
